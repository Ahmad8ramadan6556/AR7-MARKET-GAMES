# متجر شحن الألعاب

## الميزات
- تسجيل دخول عبر Google و Facebook
- نظام محفظة إلكترونية
- شحن رصيد عبر شام كاش وسيرياتيل كاش
- لوحة تحكم للمالك

## التنصيب المحلي
1. `npm install`
2. أنشئ ملف `.env`
3. `npm start`

## النشر على Railway
1. ارفع الكود إلى GitHub
2. أنشئ مشروعاً في Railway
3. أضف متغيرات البيئة
4. اضغط Deploy
